Pairs trading toolkit

Two prices that move together drift apart, then come back. These four tools check whether a pair really is tied together, how fast it snaps back, how the link changes over time, and when to trade it. Every result is fitted on the first half and tested on the second half it never saw.

Engle-Granger test

OLS + ADF on residuals
Time O(n)Space O(n)Params 2 (a, β)

Best for Pair screening · stable hedge ratios · long-run equilibrium

In practice Test both directions; use Engle-Granger critical values (about −3.34 at 5%), not plain ADF tables.

def engle_granger(lx, ly):
    a, b = ols(lx, ly)            # hedge ratio β
    e = ly - a - b * lx           # spread
    return b, adf_stat(e)         # t-stat of γ in Δe = c + γ·e₋₁

Ornstein-Uhlenbeck

Fit mean reversion
Time O(n)Space O(1)Params 3 (θ, μ, σ)

Best for Holding-period estimates · entry and exit timing · half-life screens

In practice Skip pairs with long half-lives; estimates are noisy on short samples.

def ou_halflife(s):
    phi = ols(s[:-1], s[1:]).slope   # AR(1) slope φ
    theta = -log(phi)                # mean-reversion speed
    return log(2) / theta            # half-life in days

Kalman hedge ratio

Dynamic
Time O(n)Space O(1)Params 2 (Q, R)

Best for Drifting hedge ratios · live recalibration · regime shifts

In practice Set Q (drift) and R (spread variance) from training data only; watch the innovations.

for x, y in zip(lx, ly):
    P = P + Q                     # state drifts (random walk)
    e = y - h @ th                # innovation = spread
    K = P @ h / (h @ P @ h + R)   # Kalman gain
    th, P = th + K*e, P - outer(K, h) @ P

Z-score entry rule

Fade extremes
Time O(w)Space O(w)Params 3 (w, in, out)

Best for Execution rule for mean reversion · rolling normalisation

In practice Rolling mean and std; enter at |z| > 2, take profit near 0.5, stop near |z| = 4; costs charged on every leg.

def pair_position(z, pos, z_in=2, z_out=.5):
    if pos == 0:
        return -1 if z > z_in else 1 if z < -z_in else 0
    if |z| >= 4: return 0                     # stop
    if (pos == 1 and z >= -z_out) or (pos == -1 and z <= z_out):
        return 0                              # take profit
    return pos
